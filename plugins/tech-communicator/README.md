# tech-communicator plugin

A plugin with all the necessary tools to communicate with non-technical stakeholders before and after development flows 

## Skills
1. md-to-pdf: converts markdown files (commonly created during claude code sessions) to pdfs

## Structure
```
tech-communicator-
├── .claude-plugin/
│   └── plugin.json          # plugin manifest
└── skills/
    └── md-to-pdf/
        └── SKILL.md          # example of skill directory
```
